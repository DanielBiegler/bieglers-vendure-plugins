# Bieglers Vendure Helper

VS Code Extension to improve working on Vendure projects.

## Features

### Docs Search

- Quickly find relevant Vendure Docs and open them in your browser
- Copy the URL of the highlighted item either by button or pressing CTRL+C

![Docs Search Example](./assets/docs-search-example.gif)

> [!TIP]
> 1. Configure a shortcut in VSCode settings for example `CTRL+K CTRL+V`
> 2. Select the word/s before launching the `Vendure Docs Search` command. This will automatically use your selected text as input.

## Installation

Local VS Code extensions are bundled into a `.vsix` files and can be installed by running this in your shell:

```shell
code --install-extension "./path/to/the/extension.vsix"
```
